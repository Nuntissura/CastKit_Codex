# Screenshot drop zone

Drop screenshots here when you want to reference UI/UX issues in CKC with Codex or other models.

Notes:
- Files in this folder are **ignored by git by default** (so you can dump freely without dirtying the repo).
- If you want a screenshot to be committed/shared via git, move it into: `keep/`
- Prefer filenames like: `YYYY-MM-DD__short_context.png`
