# CastKit-Codex ComfyUI Bridge

Copy or symlink this folder into ComfyUI `custom_nodes/`, then restart ComfyUI.

Set:

```text
CKC_INTAKE_URL=http://127.0.0.1:52319/intake/comfyui_output
CKC_INTAKE_CHARACTER=char_...
```

Optional:

```text
CKC_INTAKE_TOKEN=...
CKC_INTAKE_RIG=rig_...
CKC_INTAKE_OPENPOSE_REF=img_...
CKC_INTAKE_SESSION=ckc-bridge-run
```

The node is under `CastKit-Codex` and is named `CastKit-Codex Bridge`.
